# Sensor Ultrasonico
Exemplo de como ultilizar o sensor ultrasonico para projetos 

[![Simular no Wokwi](https://img.shields.io/badge/Simular%20no-Wokwi-green?style=for-the-badge&logo=autodesk)](https://wokwi.com/projects/477431220361413633)


## Como funciona?
O projeto vai utilizar um arduino e o sensor apenas
* Sensor manda dado
* Arduino lê o dado do sensor
* Arduino exibe o dado no terminal

## Materiais nescessários

| Qtd | Componente |
|-----|------------|
| 1 | Placa Arduino UNO |
| 1 | Sensor ultrasonico HC-SR04 |
| — | Fios de jumper macho-macho |
